{# The half of the player that is genuinely identical in both places it appears: the standalone /player/{id} page and Home/Library/Explore's in-page overlay. Same element ids in both, on purpose — player.js's setupPlayer/prepareAudio/setupMediaSession/setupFavorite bind by id and work against whichever is present, and the two are never in the same document. What differs between the two is only initial state, passed in by the caller (see both includers' {% with %}): duration_label — server-rendered starting value; the overlay has no track yet, so it starts at "0:00" favorite_content_id — empty for the overlay until openPlayer loads one favorite_is_on — drives the class, aria-pressed and svg fill Everything above this in the card (back link, artwork, title/channel) stays in the two callers: the page renders them from `content` server-side, the overlay starts them empty and home/overlay.js fills them in. #} {# Two interchangeable decks, not one element whose src gets reassigned per track. iOS suspends a backgrounded web app the moment it stops emitting audio, and a suspended process runs nothing at all — no timers, no fetches, and above all no media loading. Loading the next track at the instant the current one ends therefore starts a fetch the OS is about to freeze: play() hangs rather than failing, and the track begins seconds or minutes later, exactly when the app is next opened. So the next track is loaded into whichever deck isn't playing, while the current one still is (the app is awake then, by definition), and the handoff is a bare play() on already-buffered audio. Which one is live is carried by the id — everything in the app finds the player as #audio, and player.js swaps the two ids on handoff. #} {# Plays a looping, effectively-inaudible clip during the gaps when neither deck has anything to play — see player.js's keep-alive. Its own element rather than borrowing a deck, so none of the transport's listeners (seek bar, play icon, mini-player progress, media session) have to learn to ignore a source that isn't the track. #}
