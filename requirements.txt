# yt-dlp and its PO-token plugin used to be listed here, unpinned, on the
# reasoning that YouTube changes its player constantly and yt-dlp ships
# fixes within days. That reasoning still holds — but leaving them in this
# file didn't deliver it: this file barely changes, so Docker reused the
# cached `pip install` layer on every rebuild and the running image sat six
# weeks behind upstream while looking, from here, like it floated. They're
# installed in their own layer after `COPY app` instead (see Dockerfile),
# which any real change to the app invalidates. ytmusicapi sits in that same
# layer, for the same reason applied to a different moving target: YouTube
# Music's private InnerTube endpoint (see app/youtube/music.py).
